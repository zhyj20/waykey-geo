# 自学大师

面向 7 岁、即将进入小学一年级儿童的桌面浏览器自学陪伴系统。它不把教材搬成刷题页，也不显示分数、排行榜、连续打卡或倒计时。

## 现在可玩的内容

- 数学：平衡修理站、森林野餐、楼梯探险队、城市建筑师
- 语文：拼音声音实验室、绘本侦探社、汉字变形工坊、小小故事导演
- 英语：听音找朋友、小通的英语任务站、情景小剧场、英语宝物册
- 项目：筹备森林野餐、动物救援地图、我的迷你博物馆

每一个场景都遵循同一条低压力学习循环：选任务 → 先试试 → 说想法 → 换故事 → 留发现。孩子可以点击、拖放、连线配对、排序、搭建、画图、选择想法卡、行动或主动录音；不方便拖拽和画图时，始终有点选和想法卡替代路径。卡住时可自己选择“小通先等等、换一种看法、给一小线索、一起走一步、我来教小通”五种支持，而不是被直接告知答案；语文故事和英语对话还可用角色扮演表达。

首页的“小通的小世界”只会根据实际完成的场景改变；英语宝物册只会在孩子把词汇独立迁移到新故事后收进词汇。问题不是一个文本框：孩子可在问题工坊用图卡拼出“我发现 / 我猜 / 我想知道为什么 / 如果会怎样”，也可画出来，或在家长允许后录到本机；每个问题都有主题标签、后续场景和继续状态。

## 学习证据，而不是总分

系统本地记录一次具体互动的学科、概念、场景、表示方式、是否有提示、孩子的操作/图/语言摘要、仍不确定之处和下一步建议。孩子可回看自己的操作顺序、探索画和当次本地录音；录音不会跨会话保存。概念状态仅以观察口径展示：未观察 → 有提示时尝试 → 当前情境可独立 → 能解释 → 能迁移 → 隔 3—7 天仍稳定。

“稳定”至少需要两种表示、迁移和延迟回访；系统不会根据一次答对宣布“已掌握”。孩子的问题会留在发现册，成为下一次探索入口。

## 家长与隐私

家长入口使用长按防误入，能查看真实证据、未知点、下一步假设，并设置教材方向、学校主题、每次屏幕探索时长、减少动效和本地录音许可。学习数据只保存在当前浏览器；录音只留在当前会话，默认不上传，也可一键删除本机全部数据。

## 验收检查

```powershell
npm.cmd run check
```

检查会验证三科 12 场景、3 项目、五阶段证据钩子、支持阶梯、角色扮演表达、问题线、持续世界状态、英语迁移宝物、本地隐私、声音暂停/重听与录音回放、拖拽点选替代、暂停恢复、家长兴趣设置、家长入口和删除数据等实现契约；并用无浏览器依赖的运行冒烟测试走通数学五步、问题跟进、英语连线、英语迁移宝物、持续世界、角色扮演、三科路由、家长入口和数据删除。

建议人工走查：用 Tab 浏览主要按钮；关闭/打开声音；在天平拖一块积木并改用点按钮；故意选错后继续；暂停再恢复；各完成一个数/语/英场景；长按进入家长页；确认删除数据后刷新页面。
